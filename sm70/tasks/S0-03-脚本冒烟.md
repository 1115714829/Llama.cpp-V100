# S0-03 · 标准脚本冒烟（单卡 IQ1_S）

| 项 | 内容 |
|---|---|
| 执行者 | DSH |
| 依赖 | S0-02 |
| 上机 | GPU 2 |
| 允许修改 | `sm70/results/**`；BOARD 本行状态。**不许改 `sm70/tools/` 里的脚本**：脚本出错就记录原文并停手上报 |
| 预计 | 40 分钟 |

## 目的

在单卡小模型上把全套标准脚本各跑一遍，确认它们能用：起服务、就绪等待、L2 贪心门、L3 负载脚本（缩小版）、停服务、L1 形状导出与算子测试。**本任务的数字不入账**，只验证流程。

## 步骤（每条命令整条复制到 PowerShell 执行）

1. 上传脚本（确认 `TERM_OK_push`、无 `SYNTAX_ERROR`），然后加锁（必须 `LOCK_OK`）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File F:\vllm+llama.cpp\sm70\tools\push.ps1
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/lock.sh S0-03 2'
   ```
2. 生成冒烟用的小 prompt（约 2 万 token）：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'head -c 100000 /root/llm/test/sm70/prompt-256k.txt > /root/llm/test/sm70/prompt-smoke.txt; wc -c /root/llm/test/sm70/prompt-smoke.txt; echo TERM_OK_s003a'
   ```
3. 在 GPU 2 起服务（立即返回 `LAUNCHED`），然后等就绪（必须 `HEALTH_OK`）：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/rjob.sh s003srv env LIBS=/mnt/3.84t/sm70/libs/base0 TAG=s003 CARDS=2 CTX=32768 MODEL=/mnt/3.84t/Qwen3.8-27B-GGUF/Qwen3.8-27B-UD-IQ1_S.gguf bash /root/llm/test/sm70/tools/llama-std.sh'
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/wait-health.sh 8090 900'
   ```
   `HEALTH_TIMEOUT` 时：执行 `ssh -o BatchMode=yes root@192.168.50.235 'tail -40 /root/llm/test/sm70/logs/s003srv.log'`，记录原文，跳到第 8 步收尾后停手上报。
4. L2 门自检：同一服务里跑两次，第二次与第一次比（应输出 `GATE_VERDICT PASS`）：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'mkdir -p /root/llm/test/sm70/gate; python3 /root/llm/test/sm70/tools/gate.py --tag s003a > /root/llm/test/sm70/gate/s003a.txt; cat /root/llm/test/sm70/gate/s003a.txt; echo TERM_OK_s003b'
   ssh -o BatchMode=yes root@192.168.50.235 'python3 /root/llm/test/sm70/tools/gate.py --tag s003b --ref /root/llm/test/sm70/gate/s003a.txt; echo TERM_OK_s003c'
   ```
5. L3 负载脚本冒烟（1 rep、小 prompt）：先发令，再阻塞等待。工具提前超时就重发同一条 `rwait` 命令（作业在 tmux 里继续跑，不要重新发令）：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/rjob.sh s003bench env TAG=s003 REPS=1 PROMPT=/root/llm/test/sm70/prompt-smoke.txt bash /root/llm/test/sm70/tools/bench-256k.sh'
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/rwait.sh s003bench 900 30'
   ```
6. 停服务（必须 `STOPPED`），并确认服务作业结束：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/stop-llama.sh 8090'
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/rwait.sh s003srv 120 5'
   ```
7. L1 冒烟：导出形状 → 取 FLASH_ATTN_EXT（op 74）行 → 正确性 → 性能：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'mkdir -p /root/llm/test/sm70/shapes; CUDA_VISIBLE_DEVICES=2 LD_LIBRARY_PATH=/mnt/3.84t/sm70/libs/base0 /mnt/3.84t/sm70/libs/base0/test-export-graph-ops -m /mnt/3.84t/Qwen3.8-27B-GGUF/Qwen3.8-27B-UD-IQ1_S.gguf -o /root/llm/test/sm70/shapes/iq1s-ub8-c32k.txt -ub 8 -c 32768 -fa on -ctk q8_0 -ctv q8_0 > /root/llm/test/sm70/logs/s003-export.log 2>&1; echo rc=$?; wc -l /root/llm/test/sm70/shapes/iq1s-ub8-c32k.txt; echo TERM_OK_s003d'
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/shape-filter.sh /root/llm/test/sm70/shapes/iq1s-ub8-c32k.txt /root/llm/test/sm70/shapes/iq1s-fa.txt 74; echo TERM_OK_s003e'
   ssh -o BatchMode=yes root@192.168.50.235 'LIBS=/mnt/3.84t/sm70/libs/base0 python3 /root/llm/test/sm70/tools/op-perf.py /root/llm/test/sm70/shapes/iq1s-fa.txt s003fa-test 1 test; grep -a -h -e passed -e FAIL /root/llm/test/sm70/op/s003fa-test/rep1.txt | tail -5; echo TERM_OK_s003f'
   ssh -o BatchMode=yes root@192.168.50.235 'LIBS=/mnt/3.84t/sm70/libs/base0 python3 /root/llm/test/sm70/tools/op-perf.py /root/llm/test/sm70/shapes/iq1s-fa.txt s003fa 3 perf; grep -a -h FAK /root/llm/test/sm70/op/s003fa/rep1.txt | sort | uniq -c | head; echo TERM_OK_s003g'
   ```
   `SHAPES op=74 lines=0` 时：记录，跳过后两条，继续第 8 步。
8. 收尾：解锁、快照、复制原始产物：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/unlock.sh S0-03; bash /root/llm/test/sm70/tools/srv-status.sh | head -24'
   New-Item -ItemType Directory -Force F:\vllm+llama.cpp\sm70\results\raw\S0-03 | Out-Null
   scp -o BatchMode=yes -r root@192.168.50.235:/root/llm/test/sm70/runs/s003 root@192.168.50.235:/root/llm/test/sm70/op/s003fa root@192.168.50.235:/root/llm/test/sm70/op/s003fa-test F:\vllm+llama.cpp\sm70\results\raw\S0-03\
   scp -o BatchMode=yes root@192.168.50.235:/root/llm/test/sm70/gate/s003a.txt root@192.168.50.235:/root/llm/test/sm70/logs/s003srv.log root@192.168.50.235:/root/llm/test/sm70/logs/s003-export.log F:\vllm+llama.cpp\sm70\results\raw\S0-03\
   ```

## 判定

| 结果 | 条件（逐项在结果里打勾） |
|---|---|
| 完成 | ① `HEALTH_OK` ② 门自检 `GATE_VERDICT PASS`，3 个 prompt 都有 `n_tok>0` ③ summary 表 1 行、prompt_tok 在 15000–30000、AL 列不是 `-`，有 `MEM_PEAK gpu=2` ④ `STOPPED` 且 `JOB_DONE_s003srv` ⑤ 导出 rc=0 且 op 74 行数 > 0 ⑥ test 模式无 FAIL ⑦ perf 表有行，`[FAK]` 行里有内核名 |
| 部分完成 | ⑤–⑦ 有失败但 ①–④ 全过 |
| 停手上报 | ①–④ 任一失败；任何脚本报错（记录原文，**不要改脚本**） |

## 停止时的收尾

先 `stop-llama.sh 8090`（服务起来过的话），再做第 8 步；结果文件写清停在哪一步和原始报错；BOARD 本行改「待审」。
