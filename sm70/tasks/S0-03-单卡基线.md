# S0-03 · 单卡基线 + 标准脚本冒烟（IQ1_S，GPU 2，两臂）

| 项 | 内容 |
|---|---|
| 执行者 | DSH |
| 依赖 | S0-02 |
| 上机 | GPU 2 |
| 允许修改 | `sm70/results/**`；BOARD 本行状态。**不许改 `sm70/tools/` 里的脚本**：脚本出错就记录原文并停手上报 |
| 预计 | 30–40 分钟 |

## 目的

1. 跑出 **L2 单卡基线**（[BENCH.md](../BENCH.md)「L2 单卡端到端」）：IQ1_S、CTX 65536、约 5.5 万 token prompt、每臂 3 rep。
2. 顺带验证全套标准脚本：起服务、就绪等待、贪心门、负载脚本、停服务、L1 形状导出与算子测试。

| 臂 | 服务 rjob 名 | 额外 env |
|---|---|---|
| A | `s003asrv` | `LLAMA_SM70_79T=1 GGML_META_SUBGRAPH_CAPTURE=1 GGML_GALLOCR_SLOTS=1 GGML_CUDA_FA_KERNEL_DEBUG=1` |
| B | `s003bsrv` | `GGML_CUDA_FA_KERNEL_DEBUG=1` |

A 是旧工作留下的三个开关全开，B 是纯代码默认；两臂都打开 FA 路由日志（`[FAK]` 行）。

## 步骤（每条命令整条复制到 PowerShell 执行）

1. 上传脚本（确认 `TERM_OK_push`、无 `SYNTAX_ERROR`），加锁（必须 `LOCK_OK`）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File F:\vllm+llama.cpp\sm70\tools\push.ps1
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/lock.sh S0-03 2'
   ```
2. 生成 L2 prompt（已存在则不覆盖），记录字节数：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'if [ -e /root/llm/test/sm70/prompt-l2.txt ]; then echo PROMPT_L2_EXISTS; else head -c 270000 /root/llm/test/sm70/prompt-256k.txt > /root/llm/test/sm70/prompt-l2.txt; fi; wc -c /root/llm/test/sm70/prompt-l2.txt; mkdir -p /root/llm/test/sm70/gate; echo TERM_OK_s003a'
   ```

### 臂 A

3. 起服务并等就绪（必须 `HEALTH_OK`）：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/rjob.sh s003asrv env LIBS=/mnt/3.84t/sm70/libs/base0 TAG=s003a CARDS=2 CTX=65536 MODEL=/mnt/3.84t/Qwen3.8-27B-GGUF/Qwen3.8-27B-UD-IQ1_S.gguf LLAMA_SM70_79T=1 GGML_META_SUBGRAPH_CAPTURE=1 GGML_GALLOCR_SLOTS=1 GGML_CUDA_FA_KERNEL_DEBUG=1 bash /root/llm/test/sm70/tools/llama-std.sh'
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/wait-health.sh 8095 900'
   ```
   `HEALTH_TIMEOUT` 时：执行 `ssh -o BatchMode=yes root@192.168.50.235 'tail -40 /root/llm/test/sm70/logs/s003asrv.log'`，记录原文，停服务（第 6 步），跳到臂 B。
4. 贪心门自检（同一服务里两次，第二次应输出 `GATE_VERDICT PASS`）：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'python3 /root/llm/test/sm70/tools/gate.py --tag s003a-g1 > /root/llm/test/sm70/gate/s003a-g1.txt; cat /root/llm/test/sm70/gate/s003a-g1.txt; echo TERM_OK_s003b'
   ssh -o BatchMode=yes root@192.168.50.235 'python3 /root/llm/test/sm70/tools/gate.py --tag s003a-g2 --ref /root/llm/test/sm70/gate/s003a-g1.txt; echo TERM_OK_s003c'
   ```
5. 单卡负载（3 rep）。工具提前超时就重发同一条 `rwait`，不要重新发令：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/rjob.sh s003abench env TAG=s003a REPS=3 PROMPT=/root/llm/test/sm70/prompt-l2.txt bash /root/llm/test/sm70/tools/bench-256k.sh'
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/rwait.sh s003abench 1800 30'
   ```
6. 摘路由行，停服务（`STOPPED`），确认服务作业结束：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'grep -a FAK /root/llm/test/sm70/logs/s003asrv.log | sort | uniq -c | head -20; echo TERM_OK_s003d'
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/stop-llama.sh 8095'
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/rwait.sh s003asrv 120 5'
   ```

## 判定

| 结果 | 条件（逐项在结果里打勾） |
|---|---|
| 完成 | 每臂：① `HEALTH_OK` ② 门自检 `GATE_VERDICT PASS`、3 个 prompt 都 `n_tok>0` ③ summary 3 行无 `RUN_ERROR`、prompt_tok 在 50000–62000、AL 列不是 `-`、有 `MEM_PEAK gpu=2` ④ 有 `[FAK]` 路由行 ⑤ `STOPPED` 且服务作业结束；L1：⑥ 导出 rc=0 且 op 74 行数 > 0 ⑦ test 无 FAIL ⑧ perf 表有行 |
| 部分完成 | 一个臂失败但另一臂 ①–⑤ 全过；或 ⑥–⑧ 有失败 |
| 停手上报 | 两臂都失败；任何脚本报错（记录原文，**不要改脚本**）；`LOCK_REFUSED` |
