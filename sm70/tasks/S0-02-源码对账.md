# S0-02 · 源码对账 + 冻结 BASE + prompt 定稿

| 项 | 内容 |
|---|---|
| 执行者 | DSH |
| 依赖 | — |
| 上机 | 不用 GPU；写 `/root/llm/test/sm70/`、`/mnt/3.84t/sm70/` |
| 允许修改 | `sm70/results/**`；BOARD 本行状态 |
| 预计 | 20 分钟 |

## 目的

1. 证明服务器构建树与本地 `llama.cpp/` 逐字节一致，且 `/root/libdir-gb` 构建之后源码没再变过 ⇒ 这个库就是当前源码的产物。
2. 把这个库冻结成 BASE：`/mnt/3.84t/sm70/libs/base0/`。
3. 256K 标准 prompt 定稿：`/root/llm/test/sm70/prompt-256k.txt`。

## 步骤（每条命令整条复制到 PowerShell 执行）

1. 上传标准脚本，确认输出里有 `TERM_OK_push`、没有 `SYNTAX_ERROR`：
   ```powershell
   powershell -ExecutionPolicy Bypass -File F:\vllm+llama.cpp\sm70\tools\push.ps1
   ```
2. 加锁（不用 GPU，不带卡列表），必须输出 `LOCK_OK`：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/lock.sh S0-02'
   ```
3. 生成本地清单，记录 `TREE_MD5 files=N`：
   ```powershell
   powershell -ExecutionPolicy Bypass -File F:\vllm+llama.cpp\sm70\tools\tree-md5.ps1
   ```
4. 上传清单并对账，原样记录 `NEWER_THAN_REF` 行和 `TREE_MATCH` / `TREE_DRIFT` 行（DRIFT 时连同列出的差异行）：
   ```powershell
   scp -o BatchMode=yes F:\vllm+llama.cpp\sm70\results\raw\manifest-local.txt root@192.168.50.235:/root/llm/test/sm70/manifest-local.txt
   ssh -o BatchMode=yes root@192.168.50.235 'NEWER_THAN=/root/libdir-gb/libggml-cuda.so.0.24.0 bash /root/llm/test/sm70/tools/tree-check.sh; echo TERM_OK_s002a'
   ```
5. 记录本地 git 状态：
   ```powershell
   git -C F:\vllm+llama.cpp\llama.cpp log -1 --format=%H
   git -C F:\vllm+llama.cpp\llama.cpp status --short
   ```
6. 冻结 BASE 库（已存在则不覆盖），记录全部 md5 和 BUILD_MANIFEST：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'mkdir -p /mnt/3.84t/sm70/libs; if [ -e /mnt/3.84t/sm70/libs/base0 ]; then echo BASE0_EXISTS; else cp -a /root/libdir-gb /mnt/3.84t/sm70/libs/base0; date -Iseconds > /mnt/3.84t/sm70/libs/base0/FROZEN_AT.txt; fi; md5sum /root/libdir-gb/libggml-cuda.so.0.24.0 /mnt/3.84t/sm70/libs/base0/libggml-cuda.so.0.24.0 /mnt/3.84t/sm70/libs/base0/llama-server /mnt/3.84t/sm70/libs/base0/test-backend-ops; cat /mnt/3.84t/sm70/libs/base0/BUILD_MANIFEST.txt /mnt/3.84t/sm70/libs/base0/FROZEN_AT.txt; echo TERM_OK_s002b'
   ```
7. prompt 定稿（已存在则不覆盖），记录 sha256、字节数、开头 200 字符：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'if [ -e /root/llm/test/sm70/prompt-256k.txt ]; then echo PROMPT_EXISTS; else cp /root/llm/test/bl-prompt90.txt /root/llm/test/sm70/prompt-256k.txt; fi; sha256sum /root/llm/test/sm70/prompt-256k.txt; wc -c /root/llm/test/sm70/prompt-256k.txt; head -c 200 /root/llm/test/sm70/prompt-256k.txt; echo; echo TERM_OK_s002c'
   ```
8. 解锁并留快照：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/unlock.sh S0-02; bash /root/llm/test/sm70/tools/srv-status.sh | head -24'
   ```
9. 复制原始产物：
   ```powershell
   New-Item -ItemType Directory -Force F:\vllm+llama.cpp\sm70\results\raw\S0-02 | Out-Null
   scp -o BatchMode=yes root@192.168.50.235:/root/llm/test/sm70/manifest-server.txt root@192.168.50.235:/root/llm/test/sm70/manifest-diff.txt root@192.168.50.235:/root/llm/test/sm70/newer-than.txt F:\vllm+llama.cpp\sm70\results\raw\S0-02\
   ```

## 判定

| 结果 | 条件 |
|---|---|
| 完成 | `TREE_MATCH`；`NEWER_THAN_REF count=0`；两个 `libggml-cuda` md5 相同（应为 `d28f8810…`）；prompt 为 1,146,619 字节 |
| 部分完成 | `TREE_DRIFT` 或 `NEWER_THAN_REF count>0`：照常做完第 6–9 步，把差异原文写进结果 |
| 停手上报 | `LOCK_REFUSED`；push 出现 `SYNTAX_ERROR`；任何命令报错 |

## 停止时的收尾

执行第 8 步（解锁）；结果文件写清停在哪一步和原始报错；BOARD 本行改「待审」。

## 产出

`sm70/results/S0-02-源码对账.md`（按 `results/_TEMPLATE.md`）：清单文件数（本地 / 服务器）、`TREE_*` 与 `NEWER_THAN_REF` 原文、git HEAD 与 `status --short`、base0 的 md5 与 BUILD_MANIFEST、prompt 的 sha256 / 字节数 / 开头 200 字符；原始文件在 `results/raw/S0-02/`。
