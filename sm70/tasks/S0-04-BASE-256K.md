# S0-04 · BASE 的 256K 标准测试（三臂）

| 项 | 内容 |
|---|---|
| 执行者 | DSH |
| 依赖 | S0-02、S0-03 |
| 上机 | 卡 0,1,3,4 |

| 预计 | 60–70 分钟（每臂 ≈ 15–20 分钟） |

## 目的

用冻结的 BASE 库 `/mnt/3.84t/sm70/libs/base0` 跑 L3 标准测试（[BENCH.md](../BENCH.md)），三个臂：

| 臂 | rjob 名 | 额外 env | 用途 |
|---|---|---|---|
| A | `s004a` | `LLAMA_SM70_79T=1 GGML_META_SUBGRAPH_CAPTURE=1 GGML_GALLOCR_SLOTS=1` | 旧工作留下的三个开关（代码里默认关）全开 |
| B | `s004b` | 无 | 纯代码默认 |
| C | `s004c` | 同 A，另加 `SPEC=0` | 关投机的诊断臂：纯目标模型步长 |

A 与 B 的差 = 那三个开关的价值（主代理据此决定 BASE 配置）；C 给出不含投机的吐字步长。

## 步骤（每条命令整条复制到 PowerShell 执行；三个臂按 A → B → C 顺序）

1. 上传脚本并加锁（必须 `LOCK_OK`）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File F:\vllm+llama.cpp\sm70\tools\push.ps1
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/lock.sh S0-04 0,1,3,4'
   ```

### 臂 A

2. 清页缓存 → 起服务 → 等就绪（`HEALTH_OK`）：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'sync; echo 3 > /proc/sys/vm/drop_caches; echo TERM_OK_dca'
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/rjob.sh s004asrv env LIBS=/mnt/3.84t/sm70/libs/base0 TAG=s004a LLAMA_SM70_79T=1 GGML_META_SUBGRAPH_CAPTURE=1 GGML_GALLOCR_SLOTS=1 GGML_CUDA_FA_KERNEL_DEBUG=1 bash /root/llm/test/sm70/tools/llama-std.sh'
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/wait-health.sh 8095 1200'
   ```
3. 跑负载（3 rep）。工具提前超时就重发同一条 `rwait`，不要重新发令：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/rjob.sh s004a env TAG=s004a REPS=3 bash /root/llm/test/sm70/tools/bench-256k.sh'
   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/rwait.sh s004a 3600 40'
   ```
4. 摘服务日志、停服务：
   ```powershell
   ssh -o BatchMode=yes root@192.168.50.235 'grep -a -i -e draft -e accept /root/llm/test/sm70/logs/s004asrv.log | tail -8; grep -a -c -i -e error -e abort /root/llm/test/sm70/logs/s004asrv.log; grep -a -w FAK /root/llm/test/sm70/logs/s004asrv.log | sort | uniq -c | head -20; echo TERM_OK_s004a2'

   ssh -o BatchMode=yes root@192.168.50.235 'bash /root/llm/test/sm70/tools/rwait.sh s004asrv 120 5'
   ```

## 判定

| 结果 | 条件 |
|---|---|
| 完成 | 三臂各 3 rep 全部成功（summary 里没有 `RUN_ERROR`）；三臂 prompt_tok 相同；每臂都有卡 0,1,3,4 的 `MEM_PEAK` |
| 部分完成 | 某臂失败（`HEALTH_TIMEOUT`、服务作业提前结束、全部 rep `RUN_ERROR`）：记录该臂服务日志末尾 60 行（`tail -60 /root/llm/test/sm70/logs/s004Xsrv.log`），停掉该臂服务，**继续下一臂** |
| 停手上报 | `LOCK_REFUSED`；三臂都失败；`stop-llama.sh` 输出 `STOP_FAILED` |
