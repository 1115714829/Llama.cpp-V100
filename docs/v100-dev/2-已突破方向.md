## 2.2 吐字侧已突破

### T8 多槽 gallocr（B4，运行时最大单笔）

- **代码**：`ggml-alloc.c/.h` + `ggml-backend.cpp`——按图形状指纹缓存多套分配方案（LRU 多槽）；`backend_ids_changed` 命中则跳过 sync×3 + reserve。
- **效果**：均值 **50.27 → 46.99 ms/轮（-6.5%）**；tg +5～8%；机制 `[GALLOC_SLOT] hit≈98%`；draft_decode 6.0→3.4 ms/轮。
- **commit**：`aa5f84222` 等。

### DFlash2 CPU selector 并行 + 门道向量化（B1/B3）

- **代码**：`common/speculative.cpp` 8 线程并行 + gate lane 向量化默认开。
- **效果**：23.45 → **4.3 ms/轮**（早期 +26.8% 吞吐贡献）；向量化再 **-1.0%** 均值轮时。

### C4 / C5 Volta 解码内核

- **代码**：`mmvq.cu` / `mmvq.cuh`——`MMVQ_PARAMETERS_VOLTA`（ncols=1→nwarps=2）；k-quant mmvq↔mmq 交叉点 **4**。
- **效果**：tg128 **+2.8%**；Q4_K_M 小批 **+15%**。

### 正确性：DFlash2 + tensor split

- **代码**：`speculative.*`、`dflash.cpp`、`llama-model.*` 等。
- **效果**：修复硬崩，DFlash2 在 tensor TP 下可跑。

### NCCL 编入 CUDA 后端

- **效果**：早期 **+18.4%**（与 selector、P2P 同期合计把起点推到 B1）。

## 2.3 预填充侧已突破

### 墙的定位（测量结论 → 指导开发）

- 256K 预填充 **78.4%** 时间在 `FLASH_ATTN_EXT`（D=256, n_q=2048, n_kv=262144），仅 **1.49 TFLOPS**。
- 除 LM head 外 MUL_MAT 合计仅 **4.3%**；KV 每步反量化 **不是**墙（f16 KV 在 131K 更慢 31%）。

### FA-D256：Q 经 shared memory（`2168d6a28`）

- Volta D=256 路径；32K **+11.1%**、128K **+28.6%**（早期口径）。

### sm70-attn Path A（`fb2fbcdea`，预填充主成果）

| 层级 | 结果 |
|---|---|
| 算子级 | FLASH_ATTN_EXT **370.3 → 287.5 ms（-22.3%）** |
| e2e 32K | **+4.0%**（Amdahl FA 占比 19%） |
| e2e **256K** | **+17.5%**（598 → 702 t/s） |
| decode | **零回退** |
| 生产 KV | **q8_0 可走**（to_fp16 槽） |

- **代码**：`fattn-sm70-d256.cu` + `fattn-sm70-d256-kernel.cuh` + `blackmagic.h` + `sm70-vendor/` + `fattn.cu` 钩子。
- **门控**：`LLAMA_SM70_D256=1`（默认 OFF）。
- **性质**：**内核收益**，不是用户参数。
