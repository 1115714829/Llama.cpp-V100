# 1 · 计划突破方向

> 尚未突破、仍有定价头寸的**二次开发**主攻项。不含任何启动参数。

| | 值 |
|---|---|

## 1.2 吐字（decode）—— 冲 37.0

| ID | 突破方向 | 内容（代码） | 预期 | 前置 / 风险 |
|---|---|---|---:|---|
| **P-D1** | **Fix B：meta 容器停乒乓 + 内容键化** | `stc_compute[2]` 逐 compute 换容器重建镜像（`ggml-backend-meta.cpp`）；改为稳定容器 + 内容键 | **-2~5 ms/轮** | **须你批准**（E6 五次 abort 雷区；容器与 arena 生命周期耦合） |
| **P-D2** | **抬 AL / 草稿块加长 / 双块融合** | `common/speculative.cpp` 变长块、两块 8+8 合成一次 verify；绕 arena | AL 5.55→约 9，等效大砍 ms/轮 | headroom 已部分解开；变长块仍可能撞 `obj_new` |
| **P-D3** | **两 draft 合一（fused）** | 每轮 2 次 decode 合成 1 次图 | 约 **-1.7 ms/轮** | 图语义（token/embd 互斥，E4） |
| **P-D4** | **F4'：n=8 MMVQ 访存形态** | 解码 `M≈5–12` 的 Q8_0 GEMV；预取解锁 / 尾判等残杆 | -2~3（若啃下） | **六杆已灭**，余下低概率；见失败记录 |
| **P-D5** | **B2：图内 selector** | top-k/gate 入图；需 meta **跨设备合并语义**（新模式） | -2~3 ms/轮 | 红线：结构性改动**先问用户**；几何上曾受阻 |
| **P-D6** | 微款内核 | top-k 两遍扫描、gate 8×8 分块等 | 合计 ≤0.5 | 随手 |

**排序建议**：P-D1（头寸最大）→ P-D2/P-D3（抬 AL）→ P-D5（需批准）→ P-D4（低概率）→ P-D6。

到 37.0 大约要落 **P-D1 + P-D2/P-D3 中的 1–2 件**。

## 1.3 预填充（prefill）/ 256K —— 主场景

| ID | 突破方向 | 内容 | 预期 | 备注 |
|---|---|---|---|---|
| **P-P1** | **Path A 产品化** | `LLAMA_SM70_D256` 默认策略、greedy 门值重立、回归夹具 | 巩固 **256K +17.5%** | 收口项，工作量小 |
| **P-P2** | **Path B：核内 q8_0→f16** | smem 内反量化，省整条 f16 镜像 | 省 GB 级显存 + 带宽 | 参考 `fattn-q8-volta.cuh` |
| **P-P3** | **巨型 GEMM 工作分解**（1cat 路线） | QK/PV 改大 tile GEMM，rescale 降频；替换小 tile 融合 FA | 对症 1.49 TFLOPS 墙 | **结构性重写**，量级最大 |
| **P-P4** | Q-tile / SplitKV3 再调 | 按我们形状调 tile（勿照抄常量） | 个位数～10%+ | X16：照抄 −1.2% 教训 |
| **P-P5** | Path A 扩展到更多 prefill 形状 | 非 2048 n_q、混合 mask | 覆盖面 | 门控已留 |

**墙**（已定位，见已突破）：长 KV `FLASH_ATTN_EXT` ≈ 预填充 **78.4%**，仅 1.49 TFLOPS。GEMM 与 KV 反量化不是墙。

## 1.4 显存 —— 代码层（非配置）

| ID | 突破方向 | 内容 | 预期 |
|---|---|---|---|
| **P-M1** | 多槽 **预算器** | 按可用显存自动限槽/合并槽，替代「运维手设槽位」 | 长上下文防 OOM 且不失多槽收益 |
| **P-M2** | 计算缓冲生命周期收紧 | 与 P-D1 同族；降非 KV 峰值 | 中高 |
| **P-M3** | Path B（同 P-P2） | 省 f16 整镜像 | 256K 显存主项之一 |
| **P-M4** | KV 写路径去冗余 | 视图/镜像/拷贝审计 | 峰值与带宽 |

**不做**：换 Q4_K_M 省权重（模型选择，且 decode 更慢）；KV 外部压缩格式（V100 已全负）；「教用户怎么设参数」。

## 1.5 判据（计划项验收）

1. 同源 A/B，唯一变量是**代码/env 门控**（不是 `-ub`）。
2. **tg 与 ms/轮并列**；≥2 臂报离散；greedy sha256 门。
3. 机制自证计数（特性必须先证明「改的那条路真的走了」）。
4. 比 B5 差的一律不采用（写入失败记录）。
5. 大改 / 新模式：**先停下问用户**。
