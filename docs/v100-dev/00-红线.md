## 度量底线（报数/入账前）

1. **tg 与 ms/轮并列**；≥2 臂报离散；同源 A/B（唯一变量）。
2. 正确性门 **greedy sha256**；新内核须重立门值。
3. `llama-bench` 入账数字 **`-r ≥ 8`** 并报 `±`；显式 `CUDA_VISIBLE_DEVICES`。
4. 同一台机器 **禁止并发测量**；构建与测量互斥（换库会 SIGSEGV）。
5. 判投机指标看响应 JSON `timings`，不 grep 日志。
6. 特性 A/B 必须 **机制自证计数**。
7. 正式对外数字带 `drop_caches`；诊断可 `NODROP=1`（勿混用）。
8. **多线程实机互斥**（用户 2026-09-23）：任何实机测试/探针/构建前，先确认**无其他线程正在使用机器**——实机占用由**主代理统一排期**；动手前盘点 `job_list`、在跑子代理清单，并用 `nvidia-smi` 只读查询确认 GPU 无他人进程；发现占用即等待或改做非实机工作。

9. **构建清单门（R375 立规，不可绕）**：实机测量前必须 `bash /tmp/p4-build.sh`（全树清单对账，**漂移即拒绝构建**）并留存 `$LIBS/BUILD_MANIFEST.txt`（时间 / 清单 sha256 / 二进制 md5）；`p3-build.sh` 的 payload 覆盖式**停用**（曾致 `common/sampling.cpp` 的 `LLAMA_SPEC_REJ` 从未进二进制）。**新改文件必须出现在清单差异里，否则等于没改**。

## 工作规则（用户 2026-09-25，五条）

1. **等待机制**：长活 `rjob.sh` 发令即返回 → `rwait.sh` 阻塞（**5 秒** sleep 轮询）；短活命令末尾必须回显 `TERM_OK_<name>`；见终止符即结束本轮，绝不二次等待、绝不空等。
2. **目录与只读边界**：`/root/llm/llama.cpp`、`/root/llm/systemd`、`/root/llm/ac922env` 的**任何文件与服务单元只读禁止修改**；要改参数**先 copy 出来**（服务单元副本在 `p0-scripts/`，测试走自建启动器 `/root/llm/test/t1c-run.sh`）。可操作区 = `/root/llm/test/**`、`/mnt/3.84t/**`。
3. **只做硬件分支的代码优化**：启动参数调参（`-ub`／卡数／ctx／量化格式…）**不算成果**；刀必须落在 `llama.cpp/` 的代码/内核/运行时。
4. **版本与通道**：允许 `git commit`，**绝不 push / 绝不提 PR**；`llama.cpp/` 的 git remote 已移除、**不得重加**；上游协作文件（`.github/`、`CONTRIBUTING.md`、`llama.cpp/AGENTS.md`、`CLAUDE.md`）**只作参考，不执行其 PR 流程**。
5. **善用外部资源**：动手前读 [`6-外部轮子清单.md`](6-外部轮子清单.md) 与 `v100-refs/`（只读），必要时联网取一手资料（上游 PR、内核实现、论文）。

**卡数与包络（用户 2026-09-25 补充）**：**调测阶段不限卡数**（1–6 卡随意，用于快速迭代与单卡微基准）；**交差验收必须与 1cat-vLLM 同参数口径**（BL1 = `vllm-1cat.service` 原样：FP8+DFlash2、TP4 卡 0,1,3,4、256K）跑 llama.cpp，**卡数与显存只能少不能多**。
