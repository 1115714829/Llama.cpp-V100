# 00 红线与度量底线

> `AGENTS.md` 只做路由；**本文件是底线**。任何文档不得覆盖这里的红线。

## 红线（不可覆盖）

1. **绝不代用户** `git commit` / `git push` / `gh pr|issue`；不代写 commit/PR/reviewer 回复。私有 fork，不做上游贡献。
2. **只读**：`/root/llm/systemd/`、`/root/llm/llama.cpp`、`/root/llm/ac922env`、`vllm/`、`1cat-vllm/`、`vllm-forkpoint/`。
3. **服务状态保持用户交付时的状态**；只允许 `systemctl is-active` 类只读查询（除非用户明确授权腾卡）。
4. **模型只从 `/mnt/3.84t/**` 加载**，不用 `/root/llm/models/`。
5. **可操作区**：`/root/llm/test/**`、`/mnt/3.84t/**`；交付物只落 `llama.cpp/`。
6. `llama.cpp/` 源码 **仅 ASCII**；不新增 `tests/*`；**大改动/新模式先问用户**。
7. `olddoc/qwen-private/QWEN.md` **含口令**，禁止提交/分享/复制进仓库。
8. **范围**：二次开发 ≠ 调参；`-ub` 等用户配置不入成果（[`05-量化范围.md`](05-量化范围.md)）。

## 度量底线（报数/入账前）

1. **tg 与 ms/轮并列**；≥2 臂报离散；同源 A/B（唯一变量）。
2. 正确性门 **greedy sha256**；新内核须重立门值。
3. `llama-bench` 入账数字 **`-r ≥ 8`** 并报 `±`；显式 `CUDA_VISIBLE_DEVICES`。
4. 同一台机器 **禁止并发测量**；构建与测量互斥（换库会 SIGSEGV）。
5. 判投机指标看响应 JSON `timings`，不 grep 日志。
6. 特性 A/B 必须 **机制自证计数**。
7. 正式对外数字带 `drop_caches`；诊断可 `NODROP=1`（勿混用）。
